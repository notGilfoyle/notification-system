# Notification System

A simplified notification service inspired by Chapter 10 of Alex Xu's
System Design Interview.

## Features

- Email notifications
- SMS notifications
- Push notifications
- In-App notifications
- Asynchronous processing
- Worker threads
- Retry mechanism
- User preferences
- Rate limiting
- Idempotency
- Logging

## Tech Stack

- Python
- FastAPI
- queue.Queue
- threading
